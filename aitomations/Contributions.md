## Submitting Changes

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run `make validate` to check your code
5. Submit a pull request

## Code Standards

- Python: Follow PEP 8, use ruff for linting
- TypeScript/Vue: Follow the project's ESLint configuration
- All code must pass type checking
